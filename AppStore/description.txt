Delve — Development Preview

Delve is an original offline iPhone puzzle crawler. The implemented exploration slice contains three fixed, handcrafted wings totaling 45 rooms, with deterministic switches, gated doors, key pickup, and discoveries.

Explore using native SwiftUI controls with large touch targets, pause in any room, and resume a saved run after closing the app. Room scenes use clearly labeled original geometric placeholder art. Open the clue journal as a sheet over the room: write, edit, or delete a note pinned to each visited room; mark quest theories yourself while viewing separate ledger-derived goal progress; and inspect a run record with steps, sessions, and discoveries. Unrecorded counts appear as unknown rather than invented zeroes. The SwiftUI HUD and journal use scalable system text; controls have descriptive VoiceOver labels.

Accepted gameplay events and world snapshots save atomically in a local SQLite store. Resume replays the event ledger. Finishing the final chamber, retreating, or patrol-contact death returns to the entrance with an epilogue run record, preserving historical runs. No accounts, ads, in-app purchases, trackers, or networking are implemented.

Own your saves with versioned JSON backups containing run ledgers, journal notes, quest marks, and settings. Review a restore diff and explicitly confirm replacement of local data. Export journal notes and quest progress as CSV. Share either file or save it to Files. All exports and restores work offline. Finished in-game art and future dual-screen integration remain planned. Native compilation, UI journeys, and device accessibility require macOS CI/device verification; this development worktree is not an App Store release.
