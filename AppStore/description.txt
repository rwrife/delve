Delve — Development Preview

Delve is an original offline iPhone puzzle crawler. The implemented exploration slice contains one fixed, handcrafted 15-room wing with deterministic switches, gated doors, key pickup, and discoveries.

Explore using native SwiftUI controls with large touch targets, pause in any room, and resume a saved run after closing the app. Room scenes use clearly labeled original geometric placeholder art. The SwiftUI HUD supports Dynamic Type; controls have VoiceOver labels and state text/glyphs alongside color.

Accepted gameplay events and world snapshots save atomically in a local SQLite store. Resume replays the event ledger. Retreat or engine patrol-contact death returns to the entrance and preserves historical runs. No accounts, ads, in-app purchases, trackers, or networking are implemented.

Planned features include the user-owned clue journal, quest presentation, run record screen, additional wings, JSON backup/restore, CSV export, finished art, and future dual-screen integration. These features are not available in the current slice. Native compilation, UI journeys, and device accessibility require macOS CI/device verification; this development worktree is not an App Store release.
